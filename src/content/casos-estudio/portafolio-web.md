## Problema
Era necesario contar con una plataforma web que sirviera como portafolio técnico y carta de presentación para procesos de selección y reclutadores. El reto principal era que el sitio debía reflejar exactamente la filosofía de trabajo: máximo rendimiento, seguridad absoluta, accesibilidad y cero fricción, cumpliendo estrictamente con normativas de protección de datos.

## Análisis
Para garantizar tiempos de respuesta inmediatos y evitar la recopilación pasiva de datos (cumplimiento Ley 21.719), se concluyó que un backend tradicional o el uso de un CMS introducían complejidad y vulnerabilidades innecesarias para un sitio de portafolio profesional.

## Solución
Se implementó una arquitectura **Zero-Backend** basada en generación de sitios estáticos (SSG). Se diseñó una interfaz con estética técnica oscura ("Cyber", vidrio translúcido, alto contraste) y se configuraron canales de contacto directos (`mailto:`) para que la comunicación no requiera almacenar datos personales en servidores propios.

## Resultado Esperado
Proyectar una sólida imagen de rigurosidad técnica y calidad de código, logrando puntajes de 100 en métricas de rendimiento web (Core Web Vitals) y eliminando por completo los costos de mantenimiento de servidores y bases de datos.

## Tecnologías
- **Framework**: Astro
- **Estilos**: Tailwind CSS
- **Despliegue**: Cloudflare Pages
- **Patrón**: SSG (Static Site Generation)
